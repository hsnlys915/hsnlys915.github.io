I was always admiring developers and researchers having their own website powered by GitHub. I thought it was cool and showy way of demonstrating your skills and understanding and familiarity to the tools you use. 

It turned out, making it itself wasn't really complicated, thanks to detailed instructions given by GitHub, as well as others who struggled to do so beforehand.

But, for people like me, who has zero background on programming or even coding, it required quite a lot of energy to make it work. So, I am making a post to backtrack the process and hopefully help others who wants to build their own website using GitHub.

## First up, GitHub
GitHub provides free- (and paid-) online repository that enables you to upload, share, and manage your projects. While this feature is central to the use of GitHub and managing the website we will going to build along the process, they also provide something called "GitHub Page." This enables you to share and present your project in more accessible and presentable fashion.

To make use of it, we need to be registered to the<strong>
<a href="https://github.com/" target="_blank" rel="noopener">
GitHub.
</a>
</strong>

</li>

When done, click "Create repository."
